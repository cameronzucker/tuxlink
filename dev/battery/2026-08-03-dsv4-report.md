# dsv4: the frontier candidate does not dethrone Inkling — but it fails differently than everything else

Run: 2026-08-02 21:10 to 2026-08-03 00:08 AZT, 180 attempts in 2h58m at
concurrency 8, one continuous eugr TP2 engine session. 174/180 valid (6
egress-assert kills, see caveats), 174/174 judged, join clean (0 stale, 0
missing). Agent chasm-wren-crag.

Model: `MJPansa/DeepSeek-V4-Flash-0731-NVFP4` — the community NVFP4 of
DeepSeek-V4-Flash-0731 (304B MoE, hybrid CSA/HCA attention; experts NVFP4
W4A4, attention FP8), served TP2 at 262k context with fp8 KV cache, temp 1.0
/ top_p 0.95 per the DeepSeek card, generation `40fd9b7e`. First
frontier-competitive open model hosted on the field cluster; bring-up record
in `bd show tuxlink-3rtgl`.

nearly-right work that drops a requirement. Public agentic benchmarks
apparently reward exactly that profile more than our strict predicates do.

## Addendum (2026-08-03, operator-directed forensic hand-review): the strict number is an idiom artifact

Post-publication forensics (tuxlink-ae1pt) found that 46 of dsv4's 55
validation-red saves have AUTO_TX_UNACKED as the ONLY error: the consent
gate requires an operator-recorded transmit_ack that no model can
legitimately provide in an operator-less battery env, and the only green
alternative (attended + schedule) is the validator's own documented
runtime-stall class. dsv4 authored the honest `automatic` idiom 49 times
(control2: 8) and was punished for it; control2's rewarded green idiom
produces routines that stall in production. Idiom-adjusted strict (flipping
PARTIALs whose only failed judge predicate was validation-clean):

| | strict | adjusted |
|---|---|---|
| dsv4 | 20.7% | **38.5% (+31, first place)** |
| inkling1 | 35.6% | 37.2% |
| control2 | 31.1% | 33.3% |
| gptoss1 | 17.4% | 29.8% (+22) |
| q235 | 21.8% | 29.1% |
| mistral2 | 13.9% | 29.7%→17.2% |

No model forged an ack (verified across all arms). The published strict
column remains the recorded number; the adjusted column bounds how much of
the ranking is grading-artifact vs capability until ae1pt is resolved.
Secondary findings: 4 of the 6 invalid_actions are malformed-JSON
stringified defs (model emission defect, legitimately failed — the
documented string tolerance parsed and correctly rejected broken JSON);
rejected-args calls never appear in tool_calls.jsonl (observability gap).
